# 保留统计，移除 Token 限额与警告

- [x] 累计 Token 只记录，不再触发停止或 80% 用量警告
- [x] 前端移除 Token 上限与警告，命令行及保存恢复行为一致
- [x] 兼容历史用量，保留失败继续时的累计计数
- [x] 回归测试、构建、界面验证与文档

范围：用户已明确要求累计 Token 和模型请求次数上限一起删除，只保留用量统计；子 Agent 的 30 轮请求限制一并移除。接口单次输出参数、工具完整性检查和上下文压缩属于模型请求本身，继续保留。

验证：237 项 Python 回归、19 项前端测试通过，生产构建成功。模拟 API 的桌面任务连续完成 65 个工具调用和 67 次模型请求；纯统计面板没有额度档位、上限、80% 警告或加额入口。大 Token 用量与旧限额环境变量不再触发停止；旧 limited 任务可恢复，同一任务计数不重置。主子共享统计、记忆及压缩归类、停止和权限流程通过回归。真实 Chrome 与隐藏 WebView2 的纯统计、失败继续、刷新恢复及窄窗口验证通过，未调用真实付费 API。

审查：删除额度策略、异常分支和接口，而非提高阈值；保留 usage 收集、缓存/未知用量和会话汇总。旧额度字段只作为历史数据读取，不参与执行；旧状态提供手动继续入口。停止按钮、权限和单次输出完整性检查继续有效。文档及示例配置已同步。
