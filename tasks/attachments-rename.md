- [x] 输入框加号菜单提供添加文件、添加文件夹；通过系统选择器选择，引用卡片可移除
- [x] 引用按会话隔离，发送时只传路径，交给已有工具按需读取；保留原工作目录与权限流程
- [x] 项目及会话菜单提供重命名，验证名称、保存恢复；手动会话名不被第一条消息覆盖
- [x] 单元测试、构建、浏览器及真实桌面验证、文档

界面沿用现有主题、字号与菜单样式；取消选择不改变草稿。重命名只改显示名称，不改项目目录、会话编号和模型上下文。不自动展开文件夹或把文件全文塞进提示词。
