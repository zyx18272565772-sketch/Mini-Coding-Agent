# 桌面外观与聊天交互

桌面以 Codex 为视觉参考，提供字号设置、白色/深色主题、模型名称、项目与会话删除、选中复制和引用回复。

## 设计约定

参考 [Codex 官方介绍](https://openai.com/index/introducing-the-codex-app/) 与 [官方侧栏截图](https://developers.openai.com/images/codex/app/multitask-light.webp)。使用紧凑的项目/会话树、浅灰侧栏、白色聊天背景、居中阅读区、简洁的模型回复、灰色用户消息、默认折叠的执行记录，以及底部圆角输入框。深色主题同步调整全部区域。保留本项目名称及已有功能。

字号通过设置调节为 12–22px，默认 15px。聊天正文、代码和界面文字一起调整，并控制行宽、表格与代码块的滚动。新外观首次启用浅色，后续保存用户所选主题。设置、权限及删除确认均可使用键盘操作。代码、表格和任务列表通过 Markdown 插件显示，高亮资源单独构建以控制主资源大小。

## 行为

- 项目和会话通过行末菜单删除；项目删除同时删除其会话记录，弹窗显示项目名和会话数量。项目源文件、`.memory`、`.tasks` 均不删除。运行中的项目/会话禁止删除。
- 删除当前会话后切换到其余会话；全部删除后显示空状态，由用户主动新建。被删除的项目不会在重启后自动恢复。
- 输入框显示后端读取的模型标识，不向前端暴露密钥。
- 选中聊天内容后左键松开显示“回复”；点击将引用加入输入框，并可在发送前移除。发送时作为明确标注的引用文本与用户的新指令一起提交；引用不是自动执行的指令。
- 聊天区域右键菜单显示 `Copy` / `Select all`，仅复制或选中聊天内容。关闭菜单、滚动或切换会话时清理浮层。
- 引用与草稿按会话隔离，在窗口内切换会话可保留；未发送的内容不写入长期会话文件，关闭窗口后不恢复。
- 模型输出继续支持 Markdown、代码、表格、流式文本、折叠执行记录；权限面板和停止按钮保持可见。

## 验证

使用临时数据验证删除、设置恢复和模型标识；使用模拟模型验证引用发送。浏览器检查两种主题、字号、项目菜单、选择浮层和复制、流式与工具记录、320/768/1024/1440px 布局，并在真实 WebView2 检查桥接和剪贴板。不会在验收中删除用户实际项目/会话或调用付费 API。
