# 文件定位、读取与编辑

主 Agent 和子 Agent 共享以下三个工具，命令行及桌面版均通过注册表和现有权限、事件钩子调用。搜索先用 Python 标准库实现，不需要额外安装程序。

## search_files

参数：`query` 为必填的单行原文（1～200 字符），不支持正则表达式。`path` 默认为当前工作目录，也可指定子目录或单个文件；`file_glob` 默认为 `*`，可使用 `*.py`、`**/*.py` 等过滤；`max_results` 默认为 30，范围 1～200；`case_sensitive` 默认 `true`。

```json
{"query": "def login", "path": ".", "file_glob": "**/*.py", "max_results": 30}
```

返回类似 `app/auth.py:42: def login(...):` 的匹配行，每行最多显示约 300 字符的片段。下一步应使用 `read_file` 查看完整上下文。搜索结果前缀不是源码。

目录搜索跳过 `.git`、`.venv`、`venv`、`node_modules`、`__pycache__`、`dist`、`build`、`.pytest_cache`、Agent 数据目录和以 `.env` 开头的文件，不隐式跟随符号链接或 Windows 目录联接。当前使用固定忽略目录，没有解析 `.gitignore`。显式指定文件/目录时以该路径作为搜索根；工作目录外的搜索需要逐次审批。

只搜索不超过 1,000,000 字节的 UTF-8 文本。二进制、非 UTF-8、过大及无法读取的文件会跳过并给出数量；实际读取也有字节上限。最多检查 5000 个候选文件，搜索时间预算为 5 秒，返回正文约 20,000 字符。达到限制时明确报告搜索未完成，不能据此断言整个项目没有匹配；应缩小目录、文件类型或关键词后再查。跳过目录、链接和 `.env` 是默认遍历过滤，不计入跳过文件提示的数量。

## read_file

```json
{"path": "app/auth.py", "start_line": 35, "end_line": 70}
```

行号从 1 开始，包含结束行。也可以使用 `limit` 指定从 `start_line` 起读取多少行，保留旧调用兼容性；`limit` 与 `end_line` 不能同时指定。默认从第 1 行读取 200 行，每次最多 1000 行，输出正文约 20,000 字符。

返回 `42 | def login(...):` 形式的行号与原文。达到行数或字符上限时返回下一次的 `start_line`，不扫描剩余文件来统计总行数。跳过前面的行时分块读取并丢弃，内存不随整份文件增长；未请求的尾部不会整份读取或解码。超长行单独标记行内截断，给出后续行位置，截断片段不代表完整行。检测到二进制内容或 UTF-8 解码失败时返回错误。

MySQL 模式还支持读取 `artifact://编号`。这是压缩消息给出的数据库归档引用，直接作为 `path` 传入，其余分页参数及输出限制相同。例如 `{"path":"artifact://0123456789abcdef0123456789abcdef","start_line":1,"limit":100}`，其中编号必须替换为实际归档编号。查询只允许读取当前项目的正文，数据库端按行定位后返回有界片段。该引用只读，不能交给 `write_file`、`edit_file` 或 Shell 修改；旧归档的普通文件路径仍按文件读取。

## edit_file

```json
{"path": "app/auth.py", "old_text": "def login():\n    return None", "new_text": "def login():\n    return True"}
```

默认要求 `old_text` 非空且只匹配一处。零处匹配时提示重新读取；多处匹配时保留文件不变，要求增加上下文。需要全部替换时显式传 `replace_all: true`，替换全部非重叠匹配并报告数量。传入原始源码，不要复制读取结果的行号或搜索结果的路径前缀。

UTF-8 BOM 和未修改部分的字节保持原样；纯 CRLF 文件允许使用模型传回的 LF 片段匹配，并将新增换行转换回 CRLF。二进制内容拒绝编辑。当前编辑仍是整份文件读写，不提供文件版本检查、并发冲突检测或原子替换；这些属于后续可靠保存的工作。

## 典型调用顺序

`search_files` 定位 → `read_file` 读取附近代码 → `edit_file` 精确修改。匹配不唯一时重新读取更多上下文；修改后继续读取验证，按任务运行相关测试。

## 验证

文件工具测试覆盖分页续读、未请求尾部不解码、超长行、二进制、无效参数、歧义拒绝、显式批量替换及 BOM/CRLF 保留。搜索测试覆盖文件过滤、默认排除项、字面匹配、片段、扫描和结果上限。主、子循环使用真实 SDK 与模拟网络验证完整的搜索、分段读取、歧义拒绝和重新定位后修改；外部搜索验证逐次审批。`tests/desktop_file_tools_ui.cjs` 使用真实浏览器和模拟事件验证中文名称、关键词预览、默认折叠及展开结果，不调用付费模型。
